# DESIGN.md — 課堂搶答系統的視覺語彙

版本：v1.0（2026-11-19）
狀態：**本檔是介面視覺的唯一正本**。實作時依本檔與 `web/src/styles/tokens.css`；不在本檔的視覺決定不自行發揮。

---

## 1. 一句話概念

**整個系統是一份「會即時更新的試卷」。**

不是 SaaS 後台、不是卡片儀表板、不是 Material 風格後台。學生端是一張攤在桌上的**手寫試卷**，老師端是**主編的編輯台**，投影看板是教室後方的**佈告欄／計分板**。

| 畫面                  | 角色             | 學生看到的比喻                       |
| --------------------- | ---------------- | ------------------------------------ |
| 學生端 `/student`     | 一張作答中的試卷 | 考卷紙、題號、作答底線               |
| 老師端 `/teacher`     | 主編桌           | 報紙版面、欄標、細線分隔的成績表     |
| 投影看板 `/projector` | 佈告欄           | 方格紙牆、大字題號、圈出來的中獎組別 |

---

## 2. 視覺參考（本專案採用）

組員 2026-11-19 提供的兩張參考稿（`design/references/screenshots/`，不入版控）：

1. **學生作答稿**：米白紙底、黑色髮絲線、題號用極大的襯線數字、作答處是**底線**而不是輸入框、右上角紅色小標「搶答中」＋大數字倒數、左側一道朱紅垂直線。
2. **投影揭曉稿**：方格紙背景、左欄超大題號、中欄題目與揭曉（組別名被**朱紅手繪圈**起來、答案用藍色加底線）、右欄各組成功題數、底部一行朱紅標示的判斷說明。

這兩張稿就是本專案的視覺基準；實作要貼近它們，而不是貼近「常見的 AI 生成風格」。

## 3. 色彩

只有紙、墨、朱紅、藍四色。**不用漸層、不用陰影、不用圓角、不用玻璃擬態。**

| Token                  | 值        | 用途                                     |
| ---------------------- | --------- | ---------------------------------------- |
| `--color-paper`        | `#F2EEE3` | 紙底（全頁背景）                         |
| `--color-paper-raised` | `#F8F5EC` | 卡片、分塊（比紙底亮一階）               |
| `--color-ink`          | `#16130E` | 文字墨色、表格主線、按鈕底色             |
| `--color-ink-muted`    | `#6A6154` | 次要文字（說明、字數、離線）             |
| `--color-rule`         | `#C9C2B0` | 髮絲細線（1px）                          |
| `--color-vermilion`    | `#BF3B2B` | 朱紅：搶答中、目前組別、作廢、錯誤、圈選 |
| `--color-indigo`       | `#1F3A93` | 藍：已送出、答案、連結                   |

規則：

- 朱紅**只**用在「此刻正在發生的事」與「需要老師注意的事」，不當裝飾。
- 藍**只**用在「已經完成的作答／答案本身」。
- 一頁之內朱紅區塊不超過兩處，否則重點會消失。

## 4. 字體

| 角色            | 字體堆疊                                                                                 | 用途                                             |
| --------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 顯示（display） | `"Noto Serif TC", "Source Han Serif TC", "Songti TC", "PMingLiU", "SimSun", serif`       | 題號、組別名、倒數、揭曉的組別名與答案           |
| 內文（body）    | `"Noto Sans TC", "PingFang TC", "Microsoft JhengHei", "Heiti TC", system-ui, sans-serif` | 說明、表格內文、輸入的字                         |
| 欄標（utility） | 同內文，但 `letter-spacing: 0.18em`、全形、字級小                                        | 「搶答中」「本場使用公平順位」「各組成成功題數」 |

- **不用 webfont**：教室網路不穩，缺字會直接壞掉；用系統襯線堆疊（macOS 有 Songti TC / 思源宋體，Windows 有 PMingLiU / Noto Serif TC）。
- 數字用襯線體的大寫數字（`font-variant-numeric: lining-nums`），不要用等寬字型。
- 行長：內文不超過 70 個中文字；襯線大標可以到 28 字。

---

## 5. 版面與元件規則

- **線**：版面分隔一律用 1px `--color-rule`；表格主線用 1px `--color-ink`。不用 2px 以上的粗框。
- **圓角**：`0`。任何元件都不許有圓角（`--radius-medium: 0`）。
- **陰影**：一律不用。
- **按鈕**：
  - 主要動作（送出、登入、開始搶答）：墨黑底＋紙色字，方角，無陰影。
  - 次要動作（匯出、更換組別、作廢）：透明底＋1px 墨色框。
  - 停用：降成 `--color-rule` 框＋`--color-ink-muted` 字。
- **輸入**：作答框是**底線式**（只有下框線、背景透明、字用襯線體），不是方框；一般表單（密碼、組別名稱、倒數秒數）維持方框＋1px 細線。
- **區塊標題**：小字、全形寬字距，上下各一條細線（像報紙欄標），不要用卡片＋陰影。
- **表格**：只有橫線（`border-top`／`border-bottom`），不要直線格線；表頭小字寬字距。
- **投影看板**：
  - 背景是**方格紙**（48px 格，1px 細線，線色 `--color-rule`）。
  - 左欄超大題號（襯線，`--font-size-mega`）+ 小字「第 N 題」，中欄題目與揭曉，右欄各組成功題數；欄與欄之間用垂直細線分隔。
  - 搶答成功的組別名用**朱紅橢圓環**圈起來（手繪感，不是實心徽章）。
  - 答案用藍色＋底線。
- **學生端**：頁首做成「報頭」——小字「目前組別：」＋超大襯線組別名；搶答中時階段字轉朱紅；倒數用超大襯線數字（`0:24`），「剩餘時間」小字在上。

## 6. 禁用清單

以下都是本專案**明文禁止**的樣式（多半是 AI 生成介面的預設）：

1. 圓角卡片（`border-radius` > 0）、卡片陰影、`box-shadow` 任何形式。
2. 漸層（`linear-gradient` / `radial-gradient`），除了方格紙背景的 `repeating-linear-gradient`。
3. 紫藍粉等「科技藍紫」漸層按鈕、emoji 圖示、玻璃擬態。
4. 過度圓角的膠囊（pill）按鈕；只有「送出」可以是純方塊。
5. 大量卡片 + 陰影 + 大標 + 副標 + 三顆特性 icon 的「landing page」排版。
6. 純灰白背景（`#f7f7f8` 這種）＋系統 sans-serif 全站——這是本次要改掉的舊 look。
7. 動畫裝飾：只允許狀態轉換（送出、按鈕狀態）用 120–160ms 的簡單過渡；不做進場動畫、不做浮動、不做漸顯。

---

## 7. 無障礙底線（不可因為視覺而犧牲）

- 鍵盤焦點必須看得見：2px `--color-ink` 外框＋2px 間距（`:focus-visible`）。
- 對比：紙底上的墨字、藍字、朱紅字都要通過 WCAG AA（4.5:1）；朱紅只用於大字或粗體字。
- `prefers-reduced-motion` 下所有 transition 關閉。
- 語意與 aria 不得為了視覺改動（`role="timer"`、`role="status"`、`role="alert"`、標題階層維持原樣）。
- 點擊目標至少 44×44px（行動裝置作答區）。
