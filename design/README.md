# design/

介面設計的正本。AI 代理實作畫面時必須依這裡的檔案，不自行決定視覺。

| 檔案 | 內容 | 負責 |
|---|---|---|
| `DESIGN.md` | 視覺概念、色彩、字體、間距、元件規則、禁用清單 | 隊友（設計） |
| `references/REFERENCES.md` | 參考網站清單：網址、想借用的特徵 | 隊友（設計） |
| `references/screenshots/` | 參考截圖，**不進版本控制**（別人的設計，有著作權） | 各自本機 |
| `wireframes/` | 線框圖（`.drawio`） | 隊友（設計） |

流程：收集參考 → 寫 `DESIGN.md` → 畫線框圖 → 實作 → 對照 `DESIGN.md` 驗收畫面。
