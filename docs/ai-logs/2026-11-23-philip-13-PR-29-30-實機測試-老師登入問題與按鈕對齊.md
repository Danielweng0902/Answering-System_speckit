## 助理

**不要全部接受 incoming。**你只是要 review，不需要合併任何東西，最乾淨的做法是**取消這次合併**，再直接切到那個分支。

## 為什麼會有一堆衝突

`git pull 某個分支` 的意思是「**把那個分支合併進我現在所在的分支**」。你當時多半在 `main` 或其他 PR 的分支上，結果 git 試著把 `feat/014` 合併進來。前幾個 PR 都是用 squash 合併的，兩邊的歷史對不起來，就出現一堆衝突。

**為什麼全部接受 incoming 也不對：**
- 只有**有衝突的地方**會變成 PR 的版本，沒衝突的地方會保留你原本分支的內容，最後得到一份「兩邊混在一起」的程式碼，**跟 PR 實際的內容不一樣**，你 review 的就不是組員真正要合併的東西。
- 而且完成合併後，你本地的分支會多出一個合併 commit。如果你在 `main` 上，你的 `main` 就會跟 GitHub 上的不一致，之後很麻煩。

## 正確做法

**1. 取消這次合併**（一行就會回到 pull 之前的狀態）：
```powershell
cd <repo>
git merge --abort
git status
```
`git status` 應該要顯示沒有衝突。如果顯示你還有其他修改沒存，先跟我說，不要繼續。

**2. 直接切到 PR 的分支**，用「切換」，不要用「pull」：
```powershell
git fetch origin
git switch -C feat/014-typography-and-density-tokens origin/feat/014-typography-and-density-tokens
```
`-C` 的意思是：建立這個本地分支，或者如果已經有同名分支，就**直接改成跟 GitHub 上一模一樣**。這樣你拿到的就是 PR 的確切內容，不會跟任何東西合併。

**3. 確認並啟動**：
```powershell
git log --oneline -1          # 應該是 bbb488d docs(design): DESIGN.md v1.1 ...
npm run build
npm start
```

**小提醒：**要看 **#30**（組別管理同一列）的話，它是疊在 #29 上面的，切到它就**兩個 PR 的改動一起看得到**：
```powershell
git switch -C feat/015 origin/feat/015-group-list-inline-actions
```
分支名稱我是從 PR 推測的。如果顯示找不到，打 `git branch -r | Select-String 015` 看實際名稱。

以後要看別人的 PR，記得用 `git switch`（或之前教的 `git fetch origin pull/編號/head:prXX` 再 `git checkout prXX`），**不要用 `git pull 分支名稱`**。

## 助理

最可能的原因是：**你在 VS Code 的內建瀏覽器裡開老師端**，那裡存不了這版改用的登入 cookie。

## 為什麼會卡在「等待同步老師狀態」

PR #28（已合併進 `main`）把老師的登入狀態從「存在分頁裡」改成「存在瀏覽器的 cookie 裡」，流程是：

1. 你按登入 → 伺服器確認密碼正確，回傳一個 cookie。
2. 頁面重新連線，伺服器靠這個 cookie 認出你是老師，畫面才切到老師端。

VS Code 的內建瀏覽器其實是把網頁**嵌在 VS Code 的另一個頁面裡**。瀏覽器的安全規則會把這種嵌入視為「別的網站」，而這版 cookie 的設定（`SameSite=Lax`）在這種情況下**不會被存下來**。所以第 1 步看起來登入成功了，但第 2 步伺服器拿不到 cookie，還是把你當成訪客，你就一直停在登入頁，顯示「已送出登入資訊，等待同步老師狀態」。

## 解法

**直接用 Chrome 或 Edge** 開 `http://localhost:3000/teacher`，不要用 VS Code 裡的瀏覽器。

確認方法：在 Chrome 登入後按 F12 →「**Application**」→ 左邊 **Cookies** → `http://localhost:3000`，應該看到一個叫 `classroom.teacher.session` 的 cookie。有它就代表登入成功。

**如果 Chrome 也一樣卡住**，再檢查兩件事：
- **是不是有兩個伺服器在跑？**把所有跑 `npm start` 的視窗都按 Ctrl+C 關掉，只留一個，再重新 `npm run build`、`npm start`。
- **頁面是不是舊版？**在老師頁按 **Ctrl＋Shift＋R** 強制重新整理，避免瀏覽器用到快取的舊程式。

## 那個密碼警告

`[warn] 老師密碼短於 8 個字元` 只是**警告**，不是這次卡住的原因。這也是之前資安審計新增的檢查：密碼太短容易被猜到。順手把 `.env` 的 `TEACHER_PASSWORD` 改成 8 個字以上，警告就不會再出現。改完要重新 `npm start`。

## 助理

這行很關鍵，但還差一塊。

**`430[{"ok":false,"error":{"code":"FORBIDDEN",...}}]` 的意思**：這是伺服器對**某一個指令**的回覆。開頭的 `43` 代表「這是回覆」，最後的 `0` 是指令編號，表示這是這條連線送出的**第一個**指令。內容是**拒絕**：伺服器認為送出這個指令的連線**不是老師**。
