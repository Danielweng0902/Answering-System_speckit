### 問題 1（Medium）— 學生答案含 XML 1.0 禁用控制字元時，匯出的 xlsx 會是無效 XML

- **位置**：[xlsxEditor.ts:64-75](/Users/Pig0902/.t3/worktrees/Answering-System_speckit/t3-11ad048c-97c0d237c42ca366/server/src/infra/xlsx/xlsxEditor.ts)（`xmlEscape` 只處理 `&`、`<`、`>`）；送出端僅驗證答案數量（[answerCommands.ts:68](/Users/Pig0902/.t3/worktrees/Answering-System_speckit/t3-11ad048c-97c0d237c42ca366/server/src/app/answerCommands.ts)），未見字元白名單。
- **影響**：XML 1.0 不允許 `#x00–#x08`、`#x0B`、`#x0C`、`#x0E–#x1F` 出現在元素內容（即使用字元參考也無效）。任何學生可用自己瀏覽器中的 token 直接送出含 `\u0001` 的答案；該答案存入 `submission_answers` 後，若該組成為搶答成功者，`exportGuidedNotes` 產生的 `xl/worksheets/sheetN.xml` 即為無效 XML——Excel 開啟時跳出「發現無法讀取的內容」修復對話框，且**該活動之後每次匯出都失敗**（持續性破壞 C5 核心功能，除非重設活動）。CSV 不受影響（控制字元在 CSV 合法）。
- **最小 repro**：學生加入組別 → 用 devtools 對 003 送答 API/socket 送 `answers: ["\u0001A"]`（其餘空格補滿）→ 老師結束活動 → `GET /api/export/guided-notes`（Bearer 老師 token）→ 用 Excel 開啟下載檔 → 修復警告。
- **建議 regression test**：`xlsxEditor` 單元測試：`setCellText(xml, 'A1', '\u0001x')` 斷言輸出採 OOXML `_x0001_` 跳脫（或在 003 送答層拒絕/清除控制字元，並加對應送答測試）。另建議整合測試：含控制字元答案的活動匯出後以 XML parser 驗證可解析。
