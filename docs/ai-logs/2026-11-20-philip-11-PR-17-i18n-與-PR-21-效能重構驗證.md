## 這句話的意思

**VoiceOver**（iPhone／Mac）和 **NVDA**（Windows）是作業系統層級的**螢幕閱讀器**，是給視障者用的輔助工具：開啟後，它會把畫面上的文字念出來，使用者靠聽來操作網頁。它們不在系統裡，是手機和電腦本身的功能。

螢幕閱讀器要怎麼發音，是看網頁標示的語言決定的，也就是網頁最外層的 `<html lang="...">`：
- 標示 `zh-TW`：用中文規則念。這時遇到英文，可能會念得怪腔怪調，甚至一個字母一個字母念。
- 標示 `en`：用英文規則念。

PR #17 加了「繁體中文／English」切換。你 review 時指出，切換成英文後 `<html lang>` 沒有跟著改，所以組員在 `c39cb4a` 補上了：切換語言時，`<html lang>` 會同時改成 `en` 或 `zh-TW`。②那句話的意思是：**「請用螢幕閱讀器實際聽聽看，切到英文後是不是用英文口音念。」**

## 怎麼驗證

**方法 1：看標籤（30 秒，最簡單，也最直接）**
1. 用 Chrome 開系統，切到 **English**。
2. 按 **F12** → 點「**Elements**」分頁。
3. 看最上面那行，應該是 `<html lang="en">`。
4. 切回繁體中文，應該變成 `<html lang="zh-TW">`。

這就是組員修的東西。標籤對了，螢幕閱讀器就會用正確的語言念。

**方法 2：實際聽（選做，約 3 分鐘）**
Windows 不用另外下載 NVDA，內建的「**朗讀程式**」就可以：
1. 系統切到 English。
2. 按 **Ctrl＋Win＋Enter** 開啟朗讀程式。
3. 用 **Tab** 在按鈕之間移動，聽它念 "Open buzz-in" 這類按鈕名稱，應該是英文發音。
4. 切回中文再聽一次，應該是中文發音。
5. 再按一次 **Ctrl＋Win＋Enter** 關閉。

iPhone 也可以：設定 → 輔助使用 → VoiceOver。但開啟後整支手機的操作方式都會改變（要點一下選取、點兩下才會執行），不熟的話容易卡住，用電腦測比較輕鬆。

方法 1 通過，就可以回覆組員「`<html lang>` 已確認會跟著切換」。有做方法 2 的話，再補一句實際聽到的結果。
