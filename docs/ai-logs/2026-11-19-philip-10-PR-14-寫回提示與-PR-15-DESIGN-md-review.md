你說得對，那句話確實容易讓人誤會。我把原因和改法寫進 review 了。

## 為什麼會誤會

「這次沒有人作答的題目不會被清除，表上可能還留著上一場的答案。」**每次寫回成功都會出現**，包括第一次寫回、表上根本沒有舊答案的時候。老師可能會：
- 以為上一場的答案殘留了，或以為寫回出了問題；
- 看到「不會被清除」，以為系統本來應該清除、卻沒做到；
- 不知道是**哪幾題**可能有殘留，只能自己一題一題檢查。

## 建議的改法

**最好的做法：只在真的有殘留時才提醒，而且明確指出是哪幾題。**
系統寫回前本來就會重新讀取線上試算表，所以它知道每一題的答案格現在有沒有內容。只要檢查「這場沒人搶答成功的題目，答案格是不是有東西」，有的話才顯示，例如：

> 已寫回 3 格答案。第 4 題這場沒有人搶答成功，表上那一格還留著原本的內容，需要的話請自行刪除。

**簡單一點的做法：**直接拿掉這句。成功訊息只說「已寫回 N 格」，「不會清除舊答案」的說明放進 quickstart 或使用說明就好。

## 助理

可以用亮綠色，但不能把「在線」這兩個**字**直接改成亮綠色，要換一種呈現方式。

**原因：**亮綠色在米白紙底上太淡了，當成文字顏色很難看清楚。我算了幾個社群 App 常見的綠：

| 顏色 | 參考 | 在紙底上的對比 |
|---|---|---|
| `#25D366` | WhatsApp | 1.7:1 |
| `#22C55E` | 常見的「上線」綠 | 2.0:1 |
| `#31A24C` | Facebook 上線綠點 | 2.8:1 |
| `#1E9E45` | 稍深一點的亮綠 | **3.0:1** |

一般文字要 4.5:1 才算清楚，這幾個都不夠。投影在教室後排會更淡。

**解法：照社群 App 的做法，用「綠色圓點＋墨色文字」。**
Messenger、Discord 這些 App 本來就是這樣顯示的：頭像旁邊一個亮綠色小圓點，文字本身維持深色。所以：
- 「● 在線」：圓點用亮綠色，「在線」兩個字維持墨色。
- 「○ 離線」：灰色空心圓點，文字是灰色。

圓點屬於圖示，標準只要求 3:1，所以建議用 **`#1E9E45`**：看起來仍然是亮綠色，剛好達標。如果你想要更亮的 `#31A24C`（Facebook 那種），可以把圓點加一圈墨色細框，就看得清楚了。

**附帶一提：**`DESIGN.md` 禁止用 emoji，所以圓點要用 CSS 畫，不能用 🟢 符號。

review 留言的**第 2 點**換成這段：


## 使用者

還是可以改成亮綠色文字+陰影嗎(或黑色外框)

## 助理

做得到，但我不建議用在這裡，有一個更好的替代做法。

**為什麼不建議「亮綠字＋黑框（或陰影）」：**
- **中文字筆畫很密。**「在線」這種小字加了外框，框線會塞進字的空隙裡，字變得糊成一團，反而比原本更難讀。英文字母筆畫少，比較撐得住這種效果；中文小字很吃虧。
- **看起來很像早期的網頁特效。**亮綠字配黑邊，跟你們想避開的「AI 味」一樣，是一眼就看得出來的過時風格，跟紙本學習單的質感也不搭。
- **跟 `DESIGN.md` 的規定衝突**：禁用清單明文禁止陰影。要用的話，得另外為它開一個例外。

**更好的做法：亮綠色「標籤」＋黑字**
把顏色反過來，讓亮綠色當**底色**，文字用墨黑色。亮綠色一樣非常醒目，而且字很清楚。我算了一下對比：

| 底色 | 墨黑字 | 白字 |
|---|---|---|
| `#22C55E`（常見上線綠） | **8.1:1** ✅ | 2.3:1 ❌ |
| `#25D366`（WhatsApp 綠） | **9.3:1** ✅ | 2.0:1 ❌ |

墨黑字的對比遠遠超過標準。要注意的是**不能用白字**，白字在亮綠底上看不清楚。

外觀會像一個小小的方形標籤：亮綠底、黑字「在線」，方角、不加陰影，完全符合 `DESIGN.md` 的其他規定。「離線」就用灰框＋灰字的空心標籤，一眼就能區分。

如果你同意用標籤，review 的**第 2 點**換成這段：

```
2. 「在線」改為亮綠色標籤：老師端組別清單與投影看板的「在線」做成方形小標籤，
   底色亮綠 #22C55E、文字墨色 --color-ink（對比 8.1:1，通過 AA；白字只有 2.3:1，不可用白字）；
   「離線」改為透明底＋1px 灰框＋灰字的標籤。方角、不加陰影。
   請在 DESIGN.md 新增 token --color-online: #22C55E，並把 §3「只有四色」的規定改為「四色＋在線狀態綠」。
```
