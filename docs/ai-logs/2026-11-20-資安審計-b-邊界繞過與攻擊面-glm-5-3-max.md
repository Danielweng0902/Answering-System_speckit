1. **【阻擋】未認證冒名作答全鏈實測成功**：①無 token 建 websocket 收 `state` 即得全部組別 `groupId`（guest 快照含 groups id+name，[snapshot.ts:51](/Users/Pig0902/.t3/worktrees/Answering-System_speckit/t3-abac7e6c-7df3c784f3b93466/server/src/app/snapshot.ts#L51)）→ ②`POST /api/student/join` 帶該 id 免認證拿 student token → ③ open 中冒名 `answer:submit` 回 `ok:true`，老師看板顯示「第二組 submitted 冒名答案1 rank 1」。作答、題目、順位全可竊取/污染；跨組隔離本身有守住（第一組看不到）。join 無認證是 spec 設計（AC-001-09），但 guest 廣播把組別機密性歸零，需兩組做產品決策。

2. **【應修】登入速率限制可被「換位址」完全繞過**：對 127.0.0.1 猜 10 次密碼 → 429；改連 `[::1]` 立即恢復可猜（401），正確密碼從 IPv6 直接登入成功。限制以 `request.ip` 為 key（[authRoutes.ts:113](/Users/Pig0902/.t3/worktrees/Answering-System_speckit/t3-abac7e6c-7df3c784f3b93466/server/src/infra/http/authRoutes.ts#L113)），IPv6 /64 下形同虛設；且 `TEACHER_PASSWORD` 無最小長度。修：全域失敗計數＋指數退避＋密碼政策。

3. **【應修】明文 HTTP＋監聽全介面＋無 HOST 設定**：`listen(port)` 未綁 host（[index.ts:76](/Users/Pig0902/.t3/worktrees/Answering-System_speckit/t3-abac7e6c-7df3c784f3b93466/server/src/index.ts#L76)，lsof 實證 `*:59749`）；無 TLS → 老師密碼、token、學生答案在 LAN 明文可嗅探。

4. **【應修】token 永不過期、無撤銷，reset 不撤銷**：同一 teacher token 開多條連線全部有效；`activity:reset` 後舊 student token 仍有效（sessions 依 spec 保留）。與第 3 點嗅探疊加＝一次截聽、永久接管。修：sessions TTL、reset 撤銷（需兩組同意）。
