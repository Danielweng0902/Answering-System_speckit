## 這一輪只要做三件事（範圍刻意收斂，Socket.IO 的負載腳本留到下一輪）

### 1. `e2e/load/lib/measure.mjs` — 量測統計

匯出：
- `summarizeSamples(samples)` → `{ sampleCount, successCount, timeoutCount, timeoutRate, p50Ms, p95Ms, p99Ms, maxMs }`。
  - **逾時的樣本要計入分母**（sampleCount），並另外給 timeoutCount／timeoutRate。
  - 分位數用**最近秩法**（nearest-rank）：p95 = 第 ceil(0.95 × n) 小的樣本值；空樣本時各項回 null。
  - 樣本型別：`{ scheduledAt: number, completedAt: number | null, status: 'ok' | 'timeout' }`（毫秒）。
  - **單調時間不得倒退**：若 `completedAt < scheduledAt` 要 throw（含「單調時間」字樣，方便測試斷言）。
- `percentile(sortedValues, p)` helper 也一併匯出。
- 附上 `e2e/load/tests/measure.test.mjs`（用 `node:test` + `node:assert` 即可，**不要**用 vitest）：至少驗到「逾時進分母與逾時率」「p50/p95/p99 的最近秩結果」「空樣本回 null」「單調時間倒退要 throw」。

### 2. `e2e/load/lib/server.mjs` — 正式伺服器的生命週期

- 以**子程序**啟動**正式 build 的伺服器**（`node server/dist/index.js`，不是 tsx）：每次呼叫用新的暫存資料夾與新的 SQLite 檔（環境變數 `DATA_DIR`、`PORT`、`TEACHER_PASSWORD`），就緒後回傳 `{ url, port, dataDir, stop() }`，`stop()` 會關閉子程序並刪除暫存目錄。
- 就緒判斷：輪詢 `GET /api/health` 直到 200（逾時要明確報錯）。
- 老師密碼**每次隨機產生**並只放在環境變數裡，不寫檔、不印出。
- `PORT` 用 0 或一個可用的高 port，避免與其他服務衝突。

### 3. `e2e/load/http.mjs` — HTTP 負載腳本

介面：`node e2e/load/http.mjs --url <url> --rate 10,25,50 --seconds 120`，也要支援短煙霧測試（例如 `--rate 25 --seconds 10`）。
- 分開量三種負載：① `GET /api/health`（固定到達率）② `POST /api/student/join`（對已存在的組別；join 需要 groupId，先用老師 API 建組別）③ **滿房作答時用 health 探測事件迴圈**。
- 固定到達率排程、暖身 30 秒（`--warmup` 可調，煙霧測試設 2 秒）。
- 輸出每個情境的 p50/p95/p99/最大值/樣本數/錯誤率/逾時率，並用 `summarizeSamples` 計算。
- 輸出也存成 JSON（`--json <路徑>`），方便下一輪彙整。
