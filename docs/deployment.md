# 部署說明

這份文件說明**怎麼把系統擺在教室裡用**，以及每個設定背後的意義。
老師只要照「兩種上課方式」其中一種做就能上課；其餘是給要自己架主機的人看的。

> 系統的**功能行為**以 `specs/` 與 `docs/shared/FEATURE-CONTRACT.md` 為準；
> 這份文件只講部署與維運，不新增任何功能規則。

---

## 1. 兩種上課方式（先選一種）

### 方式 A：老師的電腦當伺服器（最常見，教室內用）

```bash
npm run build
npm start
```

- 學生用手機連**老師電腦的區網 IP**（例如 `http://192.168.1.23:3000/student`）。
- 怎麼查區網 IP：macOS `ipconfig getifaddr en0`、Windows `ipconfig`、Linux `hostname -I`。
- 學生和老師在同一個 Wi-Fi 即可；不需要帳號、不需要固定 IP、沒有對外連線。

**這個方式的意義**：所有資料（作答、session）都在老師的電腦裡，離開教室就沒有了，
不必擔心資料外洩或被別人連線。

### 方式 B：自己的主機／雲端主機（跨教室、跨機器用）

```bash
npm run build
HOST=127.0.0.1 PORT=3000 npm start
```

再在前面放一個反向代理（Caddy 或 nginx）對外提供 HTTPS。**不要**把 Node
伺服器直接暴露在公網：它只會講 HTTP，老師密碼、token、學生答案都會明文經過網路。

---

## 2. 部署層的意義：用「設定」把風險擋在門外

伺服器本身只是一個 Node 程序。**它預設會接受來自所有介面的連線**，
所以「誰能連到它、連上之後看到什麼」完全取決於部署層。下面每一項都是
「不改程式、用設定降低風險」的槓桿。

| 做法 | 具體動作 | 擋掉什麼 | 適用 |
|---|---|---|---|
| **綁定 host** | `HOST=127.0.0.1` | 區網裡的其他人**完全連不到** | 方式 B（有反向代理時） |
| **反向代理＋TLS** | Caddy：`example.com { reverse_proxy 127.0.0.1:3000 }` | 明文嗅探（密碼／token／答案） | 方式 B |
| **來源限制** | 在代理設 `allow 教室網段` / `deny all` | 校外的人連不進來 | 方式 B |
| **主機防火牆** | 雲端主機只開 22/443 | 對外暴露的服務 | 方式 B |
| **老師密碼夠強** | 至少 8 字元（啟動時會警告） | 密碼被猜中 | 兩種方式 |

### 為什麼 `HOST` 在方式 A 不能用

`HOST=127.0.0.1` 會讓伺服器只接受本機連線，**學生就連不到了**。
所以 `HOST` 是給「伺服器在主機上、前面有反向代理」的情境用的（方式 B）。
方式 A 不要設 `HOST`。

## 3. 環境變數

全部寫在 `.env`（已被 git 排除，**不要 commit、不要貼到群組**）。
完整清單見 [`.env.example`](../.env.example)。

| 變數 | 預設 | 意義與建議 |
|---|---|---|
| `TEACHER_PASSWORD` | （無） | 老師登入密碼。**必填**，否則系統拒絕所有老師登入（規格要求）。建議 ≥ 12 字元。 |
| `PORT` | `3000` | HTTP 埠號。 |
| `HOST` | （未設定） | 綁定位址。**只在方式 B 設成 `127.0.0.1`**；方式 A 不要設。 |
| `DATA_DIR` | `./data` | SQLite 資料檔位置。放哪裡、備份、權限都看這裡。 |
| `MAX_CONNECTIONS` | `1000` | 同時在線的 Socket.IO 連線數上限。超過時新連線被拒（403），**已連線的不受影響**，客戶端會自動退避重連，名額空出來就能進場。 |
| `JOIN_RATE_LIMIT_BURST` | `1000` | 同一個來源可以「瞬間」進場的次數。**必須容得下整班學生同時進場**（100 組班級 ≈ 400 人）。 |
| `JOIN_RATE_LIMIT_PER_MINUTE` | `30` | 同一個來源**持續**進場的速率。灌水會被壓到這個速率。 |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | （無） | 006 線上寫回 Google 試算表的服務帳號信箱。不填就沒有線上寫回（可改用下載 xlsx）。 |
| `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` | （無） | 服務帳號私鑰（PEM）。**只放 `.env`**。 |

### 為什麼進場限流是「爆發額度＋持續速率」兩個數字

`/api/student/join` 原本沒有任何節流：審計實測 **1000 次 join 在 0.6 秒內全部成功**，
每次都新增一筆 session，sessions 表因此可以無限成長。

但「一堂課的樣態」是**瞬間大量**：老師一開搶答，全班學生同時按進場，
而且在雲端部署時**全班還共用同一個對外 IP**。所以：

- `JOIN_RATE_LIMIT_BURST`（爆發額度）必須**容得下整班同時進場**（預設 1000 ≫ 400 人），
  否則會擋掉自己的學生。
- `JOIN_RATE_LIMIT_PER_MINUTE`（持續速率）才是真正對付灌水的那一環（預設 30／分）。

兩者都是 0（**任一個為 0 即整個限流不啟用**）時不限制；壓測工具就是這樣跑的，
見 `e2e/load/README.md`。

## 4. 資料與清理

- `DATA_DIR` 裡是 SQLite 資料檔（`app.db`），含作答內容、組別、以及 **session 的雜湊**。
  它**不含**密碼與明文 token（只存 SHA-256 雜湊）。
- 備份：把整個 `DATA_DIR` 複製走即可（`.env` 要另外備份，且**不要**放進同一個公開位置）。
- 權限：把 `DATA_DIR` 設成只有執行帳號能讀（例如 `chmod 700`）。
- **不要**把 `DATA_DIR` 或 `.env` 放進 `web/dist`（那是對外提供靜態檔的目錄；
  程式已擋掉 dotfile 下載，但最好的做法是根本不要放進去）。
- 課堂結束後：老師端「重設活動」會清掉**作答資料**（組別保留）；
  session 與 token 仍在。若要徹底清空，關掉伺服器後刪掉 `DATA_DIR` 即可。

## 5. 開課前的檢查清單

- [ ] `TEACHER_PASSWORD` 已設，且至少 8 字元（否則啟動時會有警告）
- [ ] 學生端網址連得上（方式 A：查區網 IP；方式 B：反向代理的網域）
- [ ] 防火牆已允許該連線埠（方式 A：Windows 要讓 Node.js 通過私人網路）
- [ ] `DATA_DIR` 指向的路徑可寫入
- [ ] 若是方式 B：已確認代理**只**轉發 `/socket.io/` 與靜態檔，並且已限制來源網段

---

## 6. 出問題時先看哪裡

| 症狀 | 先查 |
|---|---|
| 學生開不起頁面 | 防火牆、區網 IP 是否正確、代理的來源限制 |
| 一直顯示「連線中…」 | 代理是否轉發了 `/socket.io/`（WebSocket 需要 `Upgrade` 標頭） |
| 開搶答時全班同時卡住 | 連線數是否已達 `MAX_CONNECTIONS`；此時新連線會被拒，已連線的仍可用 |
| 有人一直進不了場 | 該來源的進場額度用完了，等一分鐘（`JOIN_RATE_LIMIT_PER_MINUTE` 會回補） |
