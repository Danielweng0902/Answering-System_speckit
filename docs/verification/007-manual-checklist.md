# 007 介面語言切換 — 人工驗收清單

> 這份是**給組員照著做的步驟清單**。請在瀏覽器上實際操作並記錄結果，
> 完成後把「結果」欄填進 `docs/verification/007-manual.md`（PLAYBOOK §13 要求的第三份證據）。
>
> 為什麼需要人工驗證：e2e 只能驗「有沒有切換」，
> 驗不到「英文版的排版會不會破」「中文的字有沒有被切掉」「投影看板從後排看不看得清」。

## 準備

```bash
npm run build
TEACHER_PASSWORD=<你的密碼> npm start
```

開兩個瀏覽器視窗（或同一個瀏覽器的兩個分頁）：

- **視窗 A**（老師）：`http://127.0.0.1:3000/teacher`
- **視窗 B**（學生）：`http://127.0.0.1:3000/student`

瀏覽器視窗建議寬度 **1440×900**（老師端）與 **390×844**（學生端，像手機）。

## 檢查項目

### ① 預設語言跟著系統（AC-007-01／AC-007-02）

| 步驟                                                                                | 預期                                              | 結果 |
| ----------------------------------------------------------------------------------- | ------------------------------------------------- | ---- |
| 把瀏覽器語言設成**英文**（Chrome：設定 → 語言 → 將 English 移到最上層）→ 開啟學生端 | 介面顯示 **English**                              |      |
| 關掉分頁、重新開一次學生端                                                          | 仍是 **English**（沒有被選過 → 每次都看系統語言） |      |
| 把瀏覽器語言設回**繁體中文** → 重新整理學生端                                       | 介面顯示**繁體中文**                              |      |

### ② 切換與持久化（AC-007-01）

| 步驟                   | 預期                                  | 結果 |
| ---------------------- | ------------------------------------- | ---- |
| 學生端右上角按「中文」 | **不重新載入**、介面立刻變成繁體中文  |      |
| 按 F5 重新整理         | 仍是繁體中文（`localStorage` 記住了） |      |
| 按「EN」→ 重新整理     | 仍是 English                          |      |

### ③ 跨分頁同步

| 步驟                                     | 預期                                 | 結果 |
| ---------------------------------------- | ------------------------------------ | ---- |
| 同一個瀏覽器開兩個學生端分頁，A 切到英文 | **B 也跟著變英文**（`storage` 事件） |      |

### ④ 三個畫面都切得動（AC-007-03）

| 畫面               | 預期                               | 結果 |
| ------------------ | ---------------------------------- | ---- |
| 學生端             | 右上角有「中文／EN」兩個方角小按鈕 |      |
| 老師端（登入畫面） | 同上                               |      |
| 老師端（登入後）   | 同上，且在頁首右上角               |      |
| 投影看板           | 同上                               |      |

### ⑤ 切換後整頁一致（AC-007-03）

把老師端切到英文，確認**沒有任何殘留的中文**：

| 位置         | 預期                                                | 結果 |
| ------------ | --------------------------------------------------- | ---- |
| 頁首         | 「老師端」→ Teacher；語言切換按鈕本身也換成中文／EN |      |
| 搶答控制區   | 按鈕、倒數標籤全英文                                |      |
| 匯入學習單區 | 全英文                                              |      |
| 題目清單     | 全英文                                              |      |
| 組別管理     | 「新增組別」「改名」「刪除」全英文                  |      |
| 投影看板區   | 全英文                                              |      |
| 作答看板     | 全英文                                              |      |

> 已修 → T013）。請**逐區**看過，不要只看首頁。

### ⑥ 作答流程不受影響（AC-007-04）

### ⑩ 錯誤訊息的英文（AC-007-07）

## 記錄格式

請把結果寫進 `docs/verification/007-manual.md`，至少要有：

1. 驗證日期、瀏覽器與版本、macOS／Windows

## 已知不需要驗的（已有自動化涵蓋）

- 兩種語言的 key 集合相同、每則訊息非空（單元測試）
- 插值、翻譯函式（單元測試）
- 伺服器錯誤碼的英文對照表存在（單元測試）
- `<html lang>` 的更新時機（e2e）
