## 填寫須知

- 步驟 7、10、12 是「2 秒內同步」的時間性驗收，請實際看三個分頁的更新時間，不只看結果。
- 步驟 11 要真的重啟伺服器（`Ctrl+C` 後 `npm start`），確認階段與組別都保留。
- 步驟 13 要暫時把 `.env` 的 `TEACHER_PASSWORD` 移除再啟動，測完請設回來（否則後續 002～006 的手動驗證會登入不了）。
- 不通過時請另開 GitHub issue，並在該步驟的備註欄寫上 issue 編號。
