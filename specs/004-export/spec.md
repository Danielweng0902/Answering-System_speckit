# Feature Specification: 匯出結果（export）

**Feature Branch**: `004-export`

**Created**: 2026-11-10

**Status**: Draft

**Input**: User description: "老師把搶答成功組別的答案匯出回原 Guided Notes 的填空格，並可把活動結果匯出成 CSV。依 docs/shared/FEATURE-CONTRACT.md 決策 D12、D13。"

**對應需求**：C5（主要）、E2

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 把搶答成功的答案寫回原 Guided Notes（Priority: P1）

活動結束後，老師按「匯出 Guided Notes」，得到一份與當初匯入的學習單格式相同的試算表檔，其中每一題的填空格已填入該題搶答成功組別的答案。老師可以直接開啟，或匯回 Google Sheets。

**Why this priority**: 課程核心需求：答案須寫入原本題目的填空格。對應 C5。

**Independent Test**: 匯入官方單題範本、讓兩組作答後結束，匯出並開啟檔案，確認每一題的填空格是搶答成功組別的答案，其他內容與格式與原檔相同。

**Acceptance Scenarios**:

1. **AC-004-01**（C5；對應 AC-000-08）**Given** 活動已結束且第 1 題由第一組搶答成功、答案為「CPU」，**When** 老師匯出 Guided Notes，**Then** 檔案中第 1 題的填空格內容是「CPU」。
2. **AC-004-02**（C5）**Given** 某一題無人作答，**When** 匯出，**Then** 該題的填空格與原檔相同（保持空白）。
3. **AC-004-03**（C5）**Given** 匯出的檔案，**When** 與原檔比較，**Then** 除了填空格以外，標題、題號、題目敘述、合併儲存格、欄寬、框線都與原檔相同。
4. **AC-004-04**（C5）**Given** 匯入的是版面不同的學習單（fixture 03、04、05），**When** 作答、結束並匯出，**Then** 每個答案都寫在 `expected.json` 所列的空格位置，沒有寫到其他儲存格。
5. **AC-004-05**（C5）**Given** 活動在「準備中」或「搶答中」，**When** 老師嘗試匯出 Guided Notes，**Then** 系統不提供或拒絕此操作，並說明結束後才能匯出。
6. **AC-004-06**（C5）**Given** 學生（非老師），**When** 嘗試匯出，**Then** 系統拒絕。
7. **AC-004-07**（C5）**Given** 同一場已結束的活動，**When** 老師匯出兩次，**Then** 兩次的內容相同。

---

### User Story 2 - 題組答案保留前綴（Priority: P2）

題組的填空格原本有「（1）」「（2）」這類前綴。匯出時前綴保留，答案接在前綴後面。

**Why this priority**: 屬於 E1 題組在匯出端的行為；題組範本由官方提供。

**Independent Test**: 匯入官方題組範本，第 1 題由某組搶答成功後匯出，確認兩個填空格分別是「（1）」加答案、「（2）」加答案。

**Acceptance Scenarios**:

1. **AC-004-08**（C5, E1）**Given** 題組第 1 題搶答成功的答案為「CPU」與「作業系統」，**When** 匯出，**Then** 兩個填空格的內容分別是「（1）CPU」與「（2）作業系統」。
2. **AC-004-09**（C5, E1）**Given** 題組無人作答，**When** 匯出，**Then** 填空格維持原本的前綴「（1）」「（2）」。

---

### User Story 3 - 匯出活動結果 CSV（Priority: P2）

活動結束後，老師按「匯出 CSV」，得到一份包含所有組別、所有題目作答紀錄的檔案：題號、組別、答案、順位、是否搶答成功、送出時間。

**Why this priority**: 屬於額外功能 E2，讓老師保存完整紀錄。

**Independent Test**: 兩組各送出數題後結束並匯出 CSV，用試算表軟體開啟，確認每一列與老師看板的內容一致，中文沒有亂碼。

**Acceptance Scenarios**:

1. **AC-004-10**（E2；對應 AC-000-09）**Given** 活動已結束，**When** 老師匯出 CSV，**Then** 每一筆作答的每一個空格各占一列，欄位依序為：題號、空格序、組別、答案、順位、是否搶答成功、送出時間。
2. **AC-004-11**（E2）**Given** 匯出的 CSV，**When** 與老師看板比較，**Then** 每一題各組的答案、順位、搶答成功標示完全一致。
3. **AC-004-12**（E2）**Given** 匯出的 CSV，**When** 用常見的試算表軟體直接開啟，**Then** 中文正確顯示，沒有亂碼。
4. **AC-004-13**（E2）**Given** 答案中含有逗號、引號或換行，**When** 匯出，**Then** 該答案仍在同一個欄位內，不會錯位。
5. **AC-004-14**（E2）**Given** 答案以 `=`、`+`、`-`、`@` 開頭，**When** 用試算表軟體開啟 CSV，**Then** 該內容顯示為文字，不會被當成公式執行。
6. **AC-004-15**（E2）**Given** 沒有任何組別作答，**When** 匯出 CSV，**Then** 得到只有欄位名稱列的檔案。

---

### Edge Cases

- 活動沒有匯入過題目：不能匯出，系統說明原因。
- 匯入來源是 Google Sheets 連結：匯出的仍是可下載的試算表檔；系統不直接修改雲端上的試算表。
- 填空格原本已有非前綴的內容（例如前一次的答案）：有搶答成功答案時以新答案取代；無人作答時保持原內容。
- 答案很長：完整寫入，不截斷。
- 答案以 `=` 等字元開頭：寫入 Guided Notes 時也必須是文字，不能變成公式。
- 啟用公平順位機制（005）時：匯出使用的搶答成功組別與結果畫面顯示的相同。
- 重設活動之後：原活動的結果已清空，不能再匯出。

## Requirements *(mandatory)*

### Functional Requirements

**匯出回 Guided Notes**

- **FR-001**（C5）: 老師 MUST 能在「已結束」階段匯出一份試算表檔，內容為當初匯入的學習單，並在每一題的填空格寫入該題搶答成功組別的答案。
- **FR-002**（C5）: 答案 MUST 寫入匯入時記錄的空格位置；MUST NOT 依固定的儲存格位置寫入。
- **FR-003**（C5）: 除填空格外，匯出檔的內容與格式 MUST 與原檔相同，包含合併儲存格、欄寬、框線、字型。
- **FR-004**（C5）: 無人作答的題目，其填空格 MUST 維持原檔的內容。
- **FR-005**（C5, E1）: 空格有前綴時，寫入的內容 MUST 是前綴加上答案。
- **FR-006**（C5）: 寫入的答案 MUST 是純文字，不得被試算表軟體當成公式。
- **FR-007**（C5）: 匯出檔的檔名 MUST 能辨識來源與時間（例如原檔名加上「_搶答結果」與日期時間）。
- **FR-008**（C5）: 匯出 MUST NOT 修改系統保存的原檔；同一場活動重複匯出的內容 MUST 相同。

**匯出 CSV**

- **FR-009**（E2）: 老師 MUST 能在「已結束」階段匯出 CSV，包含所有組別對所有題目的作答紀錄。
- **FR-010**（E2）: CSV 的欄位 MUST 依序為：題號、空格序、組別、答案、順位、是否搶答成功、送出時間；第一列為欄位名稱。
- **FR-011**（E2）: 一筆作答的每個空格各占一列；列的順序為題號、順位、空格序。
- **FR-012**（E2）: CSV MUST 能被常見試算表軟體直接開啟且中文不亂碼。
- **FR-013**（E2）: 含有逗號、引號、換行的內容 MUST 正確保留在同一欄位。
- **FR-014**（E2）: 以 `=`、`+`、`-`、`@` 開頭的內容 MUST 以不會被當成公式的方式輸出。
- **FR-015**（E2）: CSV 的順位與搶答成功標示 MUST 與老師看板及結果畫面一致。

**權限與條件**

- **FR-016**（C5, E2）: 兩種匯出 MUST 只有老師可以執行，且只在「已結束」階段。
- **FR-017**（C5）: 活動沒有題目時，系統 MUST 拒絕匯出並說明。

### Key Entities

- **匯出的 Guided Notes**: 原檔的副本加上搶答成功答案。屬性：檔名、產生時間。
- **結果紀錄列（Result Row）**: CSV 的一列。屬性：題號、空格序、組別、答案、順位、是否搶答成功、送出時間。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: `fixtures/guided-notes/` 中 5 份有效學習單，匯出後每個答案 100% 位於 `expected.json` 所列的空格位置。
- **SC-002**: 匯出檔中，填空格以外的儲存格內容 100% 與原檔相同。
- **SC-003**: 老師從按下匯出到取得檔案，在 5 秒內完成。
- **SC-004**: CSV 的每一列與老師看板的對應資料 100% 一致。
- **SC-005**: 匯出的試算表檔可以匯回 Google Sheets 並保持原本的版面。

## Assumptions

- 「匯出至原 Guided Notes」以產生同格式、已填答案的試算表檔實現（Feature Contract D12）；直接寫回雲端試算表列為之後的擴充，本規格不包含。此項已準備詢問助教，若答覆不同須修訂。
- 系統在匯入時已保存原檔與每個空格的位置（002）。
- 搶答成功組別與順位由 003（及啟用時的 005）決定，本子功能只讀取結果。
- 送出時間以系統收到的時間為準，格式含日期與時間到毫秒。
- 「是否搶答成功」以「是／否」表示。
- 行為規則來自 `docs/shared/FEATURE-CONTRACT.md` v0.1（Default，待 OpenSpec 組確認）。
