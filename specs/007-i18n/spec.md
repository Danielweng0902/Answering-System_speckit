# 007 介面語言切換（繁體中文／English）

狀態：實作中（2026-11-20）
分支：`feat/i18n-language-switch`

## 為什麼

課堂搶答系統會用在不同背景的學生身上（我們的班、跨校合作、國際交流）。介面目前只有繁體中文，
英文使用者看不懂題目區與作答區；老師端也只有中文。

## 範圍

- **學生端、老師端、投影看板三個畫面**都提供繁體中文／English。
- **預設依使用者的系統語言**（`navigator.languages`）：`en*` → English、`zh*` → 繁體中文、
  其他語言 → 繁體中文（本系統繁中優先）。
- 使用者用右上角的切換器改語言後，**記在 localStorage**，換頁與重新整理都保留；
  同一個瀏覽器的其他分頁也跟著變（`storage` 事件）。
- **伺服器維持回繁體中文**；錯誤訊息在**客戶端**依錯誤代碼對應英文
  （`web/src/lib/i18n/errors.ts`）。**不動共用契約**（D1～D25 都不涉及介面語言）。

## FR（功能需求）

- **FR-001**: 介面 MUST 提供繁體中文與 English 兩種語言，且**三個畫面**（學生端、老師端、投影看板）
  與首頁都要能切換。
- **FR-002**: 沒有使用者選擇時，語言 MUST 依瀏覽器的語言清單判定（`en*` → English、
  `zh*` → 繁體中文、其他 → 繁體中文）。
- **FR-003**: 使用者的選擇 MUST 記在 localStorage，重新載入後仍然有效。
- **FR-004**: 切換器 MUST 位於畫面右上角，樣式比照 `design/DESIGN.md`（方角、墨色框、無陰影）。
- **FR-005**: 語言選擇 MUST NOT 改變任何行為契約（作答流程、順位判定、寫回邏輯、快照格式）。
- **FR-006**: 螢幕閱讀器 MUST 讀到該語言的語意標籤（例如 Q1 的隱藏文字在中文版是「第 1 題」、
  英文版是「Question 1」）。
- **FR-007**: 伺服器回傳的錯誤訊息 MUST 在英文版顯示英文（依錯誤代碼對應）；
  沒有對應英文的錯誤碼顯示伺服器原文。
- **FR-008**: 訊息表 MUST 在型別上保證兩種語言的 key 相同（漏翻譯＝編譯錯誤）。

## AC（驗收條件）

1. **AC-007-01** 系統語言為英文時開啟學生端 → 介面顯示英文；切換成中文 → 立刻變中文；
   重新整理 → 仍是中文（切回英文同理）。
2. **AC-007-02** 系統語言為繁體中文時 → 介面顯示繁體中文。
3. **AC-007-03** 老師端與投影看板同樣可以切換，切換後整頁（含表格、狀態、錯誤訊息）一致。
4. **AC-007-04** 作答流程不受影響：切換語言後仍可填答、送出、看到順位與結果。
5. **AC-007-05** 螢幕閱讀器讀到的題號標籤與可讀名稱會跟著語言改變。

## 不做

- 不做伺服器端的多語言回應（錯誤訊息在客戶端翻譯即可，契約不動）。
- 不翻譯**老師上傳的學習單內容**與**學生輸入的答案**（那是資料，不是介面）。
- 另一組（OpenSpec 組）的學生端尚未實作語言切換；**共用契約不受影響**，
  但兩套系統的介面語言會不一致（之後要對齊再談）。

## 驗證

- `web/tests/i18n.test.ts`：語言判定、插值、兩種語言的 key 一致、錯誤訊息英文對應。
- `e2e/tests/007-i18n.spec.ts`：系統語言英文 → 英文介面；切換與重新整理後保留。
- 既有 e2e 的瀏覽器語系固定為 `zh-TW`（`e2e/playwright.config.ts`），
  否則介面會依系統語言變成英文、中文斷言失效。
